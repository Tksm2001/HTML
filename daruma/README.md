# かためだるま / One-Eyed Daruma

片目しか入っていない巨大だるまの死角を抜けて、もう片方の目を入れに行く。
見られている側で動くと小さなだるまにされる。仲間が 3 秒触ると戻れる。

## 仕組み（v0）

| ファイル | 役目 |
|---|---|
| `src/shared/Config.luau` | 全部の数値。手触りの調整はここだけ |
| `src/server/StageBuilder.luau` | 全ステージ共通の土台（床、左右の半分、中央線、見えない壁、スタート地点、目入れの台座、モード選びの台）と、ステージの付け替え |
| `src/server/Parts.luau` | ステージの部品を作る道具 |
| `src/server/Stages/Shrine.luau` | ステージ「だるま神社」: 鳥居、垣根、石灯籠、桜、拝殿。障害物は絵馬掛け・賽銭箱・手水鉢 |
| `src/server/Stages/Shibuya.luau` | ステージ「渋谷」: 横断歩道、ビル街と大画面、高架の電車、忠犬の銅像。歩行者信号がだるまに合わせて赤/青。障害物はバス・タクシー・工事中のコーン |
| `src/server/Stages/Fuji.luau` | ステージ「富士山」: 奥に富士山と湖、五重塔、松と紅葉、五合目の山小屋。障害物は丸太の柵・岩・お地蔵さん |
| `src/server/Daruma.luau` | だるまの体・顔・目、振り向き、目の入れ替え、視界判定 |
| `src/server/GameLoop.server.luau` | ラウンド進行、捕まえる、だるま化、救出、目入れ、勝敗 |
| `src/client/Hud.client.luau` | 画面上部の状態表示 |

ラウンドの流れ:
1. だるまが背を向けている（緑表示）→ 自由に走れる
2. 振り向く。黒目の入っている側の床が赤、白目の側が緑に光る。赤い側で動くと捕まる
3. ときどき、振り向いたあと黒目がチカチカして、入れ替わる。安全な側が逆になる
4. 黄色い台（筆が置いてある）で長押しすると目が入り、だるまが完成してラウンド終了

だるまにされたら: 仲間に 3 秒長押しで助けてもらえばその場で復活。1 人のときなどは、2 秒後に出る「やりなおす」ボタン（R キー）でスタート地点から復活できる

ステージ: 神社 → 渋谷 → 富士山 の順に、ラウンドが終わるたびに切り替わる（`Config.STAGE_ORDER`）。明るさ（昼・夕方・夜）はステージとモードごとに各ステージのファイルで決めてある。

道の障害物（`Config.OBSTACLES`）: 大きな障害物（wall）が左右交互に道をふさぐ。中央線の向こうまで伸びているので、抜けるには反対側へ渡るしかない。

新しいステージの足し方: `src/server/Stages/` に同じ形のファイル（name, nameEn, floor, centerLine, lighting, decorate, obstacle）を作り、`Config.STAGE_ORDER` と `Config.OBSTACLES` に名前を足す。

モード（スタート地点の左右の台で選ぶ。選ぶと全員スタートに戻ってやり直し）:
- ふつう: 夕方。素直なリズム
- むずかしい: 夜。柵が増える。リズムが速く、猶予が短い。背を向けてすぐ振り向く、チカチカしたのに入れ替えない（嘘）がある
