# かためだるま / One-Eyed Daruma

片目しか入っていない巨大だるまの死角を抜けて、もう片方の目を入れに行く。
見られている側で動くと小さなだるまにされる。仲間が 3 秒触ると戻れる。

## 仕組み（v0）

| ファイル | 役目 |
|---|---|
| `src/shared/Config.luau` | 全部の数値。手触りの調整はここだけ |
| `src/server/StageBuilder.luau` | 床、左右の半分、壁、目入れの台座をコードで生成 |
| `src/server/Daruma.luau` | だるまの体・顔・目、振り向き、目の入れ替え、視界判定 |
| `src/server/GameLoop.server.luau` | ラウンド進行、捕まえる、だるま化、救出、目入れ、勝敗 |
| `src/client/Hud.client.luau` | 画面上部の状態表示 |

ラウンドの流れ:
1. だるまが背を向けている（緑表示）→ 自由に走れる
2. 振り向く（赤表示）。入っている目の側の床が赤く光る。赤い側で動くと捕まる
3. ときどき目がチカチカして、入れ替わる。安全な側が逆になる
4. 黄色い台で長押しすると目が入り、ラウンド終了
