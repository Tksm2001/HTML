# かためだるま / One-Eyed Daruma

片目しか入っていない巨大だるまの死角を抜けて、もう片方の目を入れに行く。
見られている側で動くと小さなだるまにされる。仲間が 3 秒触ると戻れる。

## 仕組み（v0）

| ファイル | 役目 |
|---|---|
| `src/shared/Config.luau` | 全部の数値。手触りの調整はここだけ |
| `src/server/StageBuilder.luau` | だるま神社のステージ（参道、鳥居、垣根、石灯籠、桜、拝殿、目入れの台座、モード選びの台）をコードで生成 |
| `src/server/Daruma.luau` | だるまの体・顔・目、振り向き、目の入れ替え、視界判定 |
| `src/server/GameLoop.server.luau` | ラウンド進行、捕まえる、だるま化、救出、目入れ、勝敗 |
| `src/client/Hud.client.luau` | 画面上部の状態表示 |

ラウンドの流れ:
1. だるまが背を向けている（緑表示）→ 自由に走れる
2. 振り向く。黒目の入っている側の床が赤、白目の側が緑に光る。赤い側で動くと捕まる
3. ときどき、振り向いたあと黒目がチカチカして、入れ替わる。安全な側が逆になる
4. 黄色い台（筆が置いてある）で長押しすると目が入り、だるまが完成してラウンド終了

モード（スタート地点の左右の台で選ぶ。選ぶと全員スタートに戻ってやり直し）:
- ふつう: 夕方。素直なリズム
- むずかしい: 夜。リズムが速く、猶予が短い。背を向けてすぐ振り向く、チカチカしたのに入れ替えない（嘘）がある
