# 4 本目: 『バンカーの大冒険』（仮）— ローグライク RPG

不思議のダンジョン系（トルネコの大冒険）への **オマージュ**。名前・見た目・固有名詞はすべてオリジナルにする（他社 IP は一切出さない）。
前作: `../daruma`, `../yokai`, `../onigiri`。進め方・技術はそれらの HANDOFF と同じ（Rojo → Studio MCP でテスト、コードは全部 Claude）。

## 一言で
「入るたびに形が変わる **マネータワー** を駆け上がり、倒れても **キャリア（ランク）** だけは残る。新人バンカーが何度も挑んで一流のエリートになる物語」

## トルネコとの対応（オマージュの芯）
| トルネコ | このゲーム |
|---|---|
| 商人トルネコ | 新人投資銀行員 **タクト**（主役。かわいい 2.5 頭身、スーツに大きなカバン） |
| 不思議のダンジョン | **マネータワー**（入るたびに間取りが変わる。1F→上へ「駆け上がる」） |
| ターン制（1 歩動くと敵も 1 歩） | 同じ。マス目を 1 歩ずつ。考える時間は無限 |
| 倒れると持ち物を失う | 同じ。ただし **ランク（キャリア）と物語の進みは失わない** |
| 街・店・倉庫 | **本社オフィス**（拠点）。売店、ロッカー（倉庫）、上司の部屋（物語） |
| 剣・盾・草・巻物・杖 | 万年筆（武器）・スーツ（防具）・コーヒー（回復）・名刺（巻物）・電卓（杖） |
| ゴールド | **円** |

## ストーリー（回数を重ねるごとに出世）
拠点のオフィスで、挑戦回数と到達階に応じてランクが上がり、肩書きが変わり、上司や同僚のセリフとオフィスの見た目が変わる。
| ランク | 肩書き | 解放 |
|---|---|---|
| 0 | 新人（インターン） | 1〜5F まで。チュートリアル |
| 1 | アナリスト | 10F。売店に防具 |
| 2 | アソシエイト | 15F。ロッカー（持ち込み 1 枠） |
| 3 | VP | 20F。電卓（杖）が店に |
| 4 | ディレクター | 25F。ライバル登場 |
| 5 | MD（マネージングディレクター） | 30F 最上階「取締役会」ボス |
| 6 | 伝説のバンカー | エンドレス塔（記録更新を競う） |

登場人物（すべてオリジナル）
- **タクト**: 主役。やる気だけはある新人
- **部長 カネモト**: 厳しいが見守る上司。ランクアップのたびに一言
- **先輩 ミサキ**: 売店とチュートリアル担当
- **ライバル ハヤテ**: 他社のエリート。ランク 4 から塔の中で競う
- 塔の主 **「ダークマネー」**: 最上階のボス。「お金はこわいもの」の象徴（怖すぎない見た目）

敵（損失のモンスター。かわいく、ひと目で分かる）
あかじくん（赤字。最弱）／ バブルん（大きくなって割れる）／ リスクのカゲ（見えにくい）／ 不良債権ワニ／ インフレねずみ（増える）／ 手数料コウモリ（円を盗む）／ 為替カメレオン（色で強さが変わる）／ 利息ヘビ（毎ターン削る）／ 破産おばけ（レア、倒すと大金）／ 取締役会（ボス）

## 遊びの 1 周（ランは 5〜15 分）
1. オフィスで装備・コーヒーを買う（円は塔から持ち帰った分）
2. タワーへ。各階はランダムな部屋＋通路。階段を見つけて上へ
3. 敵を倒すと経験値（その周だけのレベル）。宝箱・落ちている物を拾う
4. 倒れる → 持ち物と円はなくなる。**オフィスに戻ると挑戦回数と最高到達階でランクアップ判定**、物語が進む
5. 「帰還の名刺」を使えば持ち物と円を持って帰れる（引き際の判断がゲームの味）

## 凝った中身（利用者「かなり凝った中身にしてください」2026-10-06）
不思議のダンジョンの「味」を一通り入れる。名前は全部この世界の言葉に置き換える。
- **やる気ゲージ**（満腹度）: 1 歩ごとに減る。0 だと HP が減る。弁当・おにぎりで回復。コーヒーは HP 回復
- **未識別アイテム**: 名刺（巻物）と電卓（杖）は拾った時点では「？の名刺」。使うか「鑑定の名刺」で判明。周をまたいで名前は覚えない（毎回ランダム割り当て）
- **罠**（床に隠れている。踏むか、調べると見える）: 残業トラップ（やる気 −30）、会議ワープ（別の部屋へ飛ぶ）、転倒（持ち物を 1 つ落とす）、システム障害（電卓の残り回数 0）、非常階段（強制的に次の階へ）、監査の呼び出し（敵が集まる）
- **状態異常**: 居眠り（数ターン動けない）、寝不足（移動がランダム）、ストレス（毎ターン HP −1）、強気（攻撃 2 倍、数ターン）
- **装備**: 万年筆（攻撃）・スーツ（防御）に +1〜+9 の強化値。「合成の名刺」で同じ種類を合体すると強化値が足される。ネクタイ（アクセサリ: 罠無効、やる気減らない、など 1 効果）
- **投げる**: どの道具も投げられる。コーヒーを投げると敵が回復してしまう（笑い）、電卓は振る（直線に効果）
- **特殊な部屋**: 監査室（モンスターハウス: 入ると一斉に起きる）、金庫室（宝が多いが罠も多い）、臨時売店（先輩ミサキが塔の中で開店。買う・売る。万引きすると全階の敵が追う… は Roblox 向けにナシ。代わりに「売店の店番コウモリ」）
- **特別な階**: 5 の倍数の階は「昇進試験」= 固定の間取りで中ボス（部長ではなく「クライアント」。倒すのではなく「プレゼンに勝つ」= 同じ戦闘ルール）
- **ボス**: 30F「取締役会」= 3 体の役員を同時に相手。最上階に「ダークマネー」
- **敵ごとの個性（10 種 + ボス）**: 分裂する、円を盗んで逃げる、見えない、装備を錆びさせる（ワニ）、レベルが上がる（ヘビは倒した敵を食べる）、眠らせる、倍々に増える（インフレねずみ: 放置すると部屋が埋まる）
- **部下（仲間）**: ランク 3 から、塔内で助けた「迷子のインターン」が 1 周だけついてくる（簡単な AI: 近い敵を攻撃）
- **周ごとの記録**: 到達階、倒した数、拾った円、周の時間。オフィスの壁に「社内ランキング」
- **物語**: ランクが上がるたびに部長のセリフ、ライバルの登場、オフィスの模様替え（新人は隅の机 → MD は個室）。エンディングは「伝説のバンカー」で塔の真実（ダークマネーは昔のバンカーの欲）が明かされる

## Roblox で定着させる仕掛け
- 明日も来る: 毎日 1 回「本日の案件」（決まった種のタワー。全員同じ間取りで到達階ランキング）
- 友達と来る: 2 人同時入塔（同じフロアで交代ではなく、**両方が動いたら敵が動く**同時ターン制）。まずは 1 人用を完成させ、2 人用は後
- 見た目の売り場（後回し）: スーツの色・カバン・ネクタイ。ゲーム内コインだけ（前作と同じ決まり）
- 年齢区分は「極少」狙い: ギャンブル表現なし（投資は「仕事」として描く。賭けの演出はしない）、血なし、怖すぎる見た目なし

## 技術の方針
- ターン制グリッド: サーバーが真実（マップ・敵・持ち物）。クライアントは WASD/タップで「1 歩」を送るだけ
- 1 人 1 塔: プレイヤーごとにワークスペースの別区画（X 方向に 500 スタッド離す）に自分の階を組み立てる。他人の階は見えない
- 階の生成: 部屋 3〜6 個を配置し通路でつなぐ（古典的な BSP でなく、部屋をランダムに置いて L 字通路でつなぐ簡単版）
- 保存: DataStore（ランク・挑戦回数・最高階・ロッカー・円の貯金）
- キャラ: 前作同様パーツ組み立て（Cute.luau の顔道具を流用してよい。キャラ自体は新規）

## ファイル構成（Rojo: `default.project.json` → `C:\Rublox\Banker.rbxl`）

- `src/shared/Items.luau` 道具 36 種（万年筆・スーツ・ネクタイ・弁当・コーヒー・名刺・電卓・円）、`Items.roll / make / displayName`（未識別は「？白い名刺」）
- `src/shared/Monsters.luau` 敵 12 種 + クライアント・取締役・ダークマネー。`special` が個性
- `src/shared/Story.luau` 部長・先輩・ライバルのセリフ（INTRO / RANK_UP[2..7] / ENDING / FAIL / RETURN）
- `src/shared/Chars/Cute.luau` 顔の道具（おにぎりーずと同じ）、`Chars/Designs.luau` 人 7 + 敵 13 のビルダー。`Designs.build(id, cf, parent)`
- `src/server/MapGen.luau` 1 階の間取り（部屋をランダムに置いて L 字通路。監査室・金庫室・臨時売店。5 の倍数は試験、30F は取締役会）
- `src/server/Run.luau` 1 周の本体（ターン・戦闘・道具・罠・敵 AI・部下・売店・snapshot）。サーバーだけが真実
- `src/server/Profile.luau` DataStore `BankerTower_v1`（points / runs / bestFloor / yen / bag / locker / history / daily）
- `src/server/Office.luau` オフィスの建物と NPC（ProximityPrompt）
- `src/server/GameServer.server.luau` 司令塔。Remote: `GameEvent`(S→C: run / runEnd / profile / dialog / openShop / openLocker / toast) `GameRequest`(C→S: step / wait / climb / use / throw / drop / face / buy / sell / giveup / shopBuy / shopSell / lockerPut / lockerTake / bagEquip / talk / introDone) `GetProfile`。Studio だけ `ServerStorage.Cheat`（yen / points / item <id> / mon <id> / tp x,y / floor n / start [daily] / hp n / reveal）
- `src/client/Dungeon.client.luau` 塔の見た目（自分だけ。ORIGIN (0,300,1200) に部品を置く）、カメラ、操作（WASD/矢印/十字ボタン、Shift+方向で向きだけ、Q まつ、E のぼる）、演出
- `src/client/RunUI.client.luau` HP/やる気/ログ/持ち物/臨時売店/結果。`PlayerGui.RunUI.Test` BindableEvent はテスト用（inv / shop / close）
- `src/client/OfficeUI.client.luau` キャリア表示、会話、売店（ランクで品ぞろえ）、持ち物・装備、ロッカー。`PlayerGui.OfficeUI.Test`（bag / locker / shop / close）
- `src/client/Sounds.client.luau` 効果音

## テストのしかた（Claude 用）
- 画面なしの論理テスト: scratchpad の `btest.lua` を Edit モードで execute_luau（Run をクローンして 6 周ランダム歩行 + 全階生成）
- 画面テスト: Play 中は `screen_capture` が固まるので、`wshot.py Banker out.png`（デスクトップから Studio の窓を切り出す）。窓にフォーカスして 3D ビューをクリックしないと描画が止まったままになる
- `bround.sh / bround2.sh / bround3.sh` に一連の流れ（売店→周→敵→死亡／昇進→帰還／本日の案件→塔内売店）
- クライアントの snapshot 要点は `player:GetAttribute("Snap")` で読める
